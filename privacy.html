隐私政策 (Privacy Policy)

MESL Cloud 机场把捍卫每位用户的个人数字隐私和信息安全作为系统的最高准则。本政策向您透明公开我们严格的数据处理规范。

【绝对无日志誓约】：MESL Cloud 机场坚决奉行“零网络活动日志 (Strict No-Logs Policy)”！我们绝不记录、绝不保存、绝不追踪、绝不出售任何用户的网络浏览轨迹、数据内容或 DNS 请求！

一、 物理级杜绝收集的信息

我们的系统基于内存瞬时路由与无状态转发机制设计，从物理架构层面确保不具备记录以下信息的能力：

  • 不收集用户的访问网址与浏览记录：不保存您访问的任何具体页面、目标服务器或在线活动。
  • 不收集用户的传输内容数据：所有流量在端到端均经过高级密码学加密封装，无留存、无解密。
  • 不收集用户的真实物理 IP 地址：用户建立专线会话时，连接元数据仅在内存短暂驻留，断开即随内存清空而湮灭。
  • 不收集任何 DNS 查询历史：使用全自建私有加密 DNS 递归集群，防止任何外部嗅探行为。

二、 仅保留的必要管理数据

为维护账户订购与基础计费周期，我们仅在数据库中保存以下最小必要信息：

  • 注册电子邮箱地址（用于登录身份验证与重要系统告警通知）。
  • 当前周期流量配额与消耗总量（纯统计数值，不与任何具体浏览内容挂钩）。
  • 当前在线并发设备数（仅用于防止超出套餐额定设备上限）。

三、 高强度传输加密标准

所有节点骨干通信均采用前沿的高强度加密协议（如 ChaCha20-Poly1305 / AES-256-GCM 与 AEAD），杜绝任何网络中间人攻击。
